# Данные

Библиотека работает с **сырыми файлами GFS 0.25° (GRIB2)** — анализами
и прогнозами; их не нужно ни конвертировать, ни обрезать:
`atmostab.open_gfs()` читает GRIB2 напрямую (через cfgrib), вырезка
области задаётся параметром `region` / опцией CLI `--region`.

## Источник данных

Архив **NCEP GFS 0.25° — UCAR/RDA dataset [d084001](https://gdex.ucar.edu/datasets/d084001/)**
(именно из него взяты данные ВКР; лицензия CC BY 4.0, покрытие — с
15.01.2015 по настоящее время, сроки 00/06/12/18 ВСВ, анализы и
прогнозы до f384).

## Скачивание

В комплекте есть модуль скачивания:

```bash
# основной сценарий: прогноз свежего запуска на +12 ч
atmostab-download $(date +%F) --hours 6 --forecast-hours 12 --out data/gfs

# несколько сроков подряд — для карт тенденций
atmostab-download $(date +%F) --hours 6 --forecast-hours 12,15,18 --out data/gfs

# прогнозные сроки запуска 19.05.2021 (кейс пыльной бури из ВКР);
# в прогнозных файлах есть спиральность (SRH), она нужна для индекса EHI
atmostab-download 2021-05-19 --hours 12 --forecast-hours 3,6,9,12 --out data/gfs

# данные за 2016 год и старше — из архива UCAR/RDA (d084001)
atmostab-download 2016-05-14 --hours 12 --forecast-hours 3 --source gdex \
    --out data/gfs --insecure
```

Как это работает:

* источник `noaa` (по умолчанию, анонимно) — открытое хранилище NOAA
  `noaa-gfs-bdp-pds` на AWS S3 (примерно с конца февраля 2021 г.).
  Полный файл GFS ~450 МБ не скачивается: сначала читается
  сопутствующий индексный файл `.idx` с байтовыми смещениями сообщений
  GRIB, затем только нужные сообщения забираются Range-запросами.
  Итог — валидный GRIB2 на 40–60 МБ: профиль ветра 1000–250 гПа (для
  BRN), T/RH/q/HGT на 1000–500 гПа, CAPE/CIN/Lifted index/давление у
  земли и (в прогнозных файлах) SRH, T на 2 м, ветер на 10 м. Сетка
  сроков прогноза: шаг 3 ч до f120, далее 12 ч до f384.
* источник `gdex` — UCAR/RDA d084001, файл скачивается целиком
  (~450 МБ). Сервер UCAR отдаёт самоподписанный сертификат (`--insecure`)
  и может требовать авторизацию (cookie через `--cookie`).

## Использование скачанных файлов

```python
import atmostab
from atmostab import indices

# сырой GRIB2, вырезка области (запад, восток, юг, север)
ds = atmostab.open_gfs("data/gfs/gfs_20210519_12_f000.grib2",
                       region=(15, 55, 38, 53))
ki = indices.k_index(ds)
sweat = indices.swet(ds)
```

или сразу карты (индексы перечисляются обязательно):

```bash
atmostab data/gfs/*.grib2 --index KI,TT,SWEAT,EHI -o figures \
    --region 15,55,38,53 --tendency
```

## Демо-данные `data/sample/`

Две небольших (1–3 МБ) NetCDF-вырезки для запуска без скачиваний:
анализ GFS за 19.05.2021 12:00 и 18:00 ВСВ — случай пыльной бури в
Астраханской области (61×161 точки: 38–53° с.ш., 15–55° в.д.). Исходно
они подготовлены из файлов датасета d084001.

### Переменные в NetCDF-вырезках

Координаты: `lat`, `lon` (0.25°), `level3` — изобарические поверхности в
мбар (1000–250 гПа), `time` (срок анализа). В `atmostab.open_gfs`
координата переименовывается в `isobaric`, уровни выбираются по
значению.

| Переменная | Содержание | Единицы |
|---|---|---|
| `TMP_L100` | температура на изобарических поверхностях | К |
| `R_H_L100` | относительная влажность | % |
| `SPF_H_L100` | удельная влажность | кг/кг |
| `U_GRD_L100`, `V_GRD_L100` | составляющие ветра | м/с |
| `HGT_L100` | геопотенциальная высота | гпм |
| `CAPE_L1` | CAPE приземной частицы | Дж/кг |
| `CIN_L1` | CIN | Дж/кг |
| `LFT_X_L1` | surface lifted index | K |
| `HLCY_Y103` | спиральность слоя 0–3 км | м²/с² |
| `TMP_L1` | температура воздуха у земли (~2 м) | К |
| `PRES_L1` | давление у земли | Па |

## Наблюдения станции `data/station/`

`astrakhan_20210519.csv` — 3-часовые наблюдения метеостанции Астрахань
за 19–20 мая 2021 г. (16 сроков, ВСВ). Используются только для
демонстрационного графика в README: сопоставления расчётных полей с
тем, что реально наблюдалось (в 15:00 ВСВ — сильная пыльная буря,
видимость 200 м, ветер до 21 м/с). В расчёте индексов эти данные не
участвуют.

## Проверка случаев по наблюдениям

Независимая проверка того, что явления действительно наблюдались:
архив погоды метеостанций [rp5.ru](https://rp5.ru/). Для случая
пыльной бури — [Архив погоды в Астрахани](https://rp5.ru/%D0%90%D1%80%D1%85%D0%B8%D0%B2_%D0%BF%D0%BE%D0%B3%D0%BE%D0%B4%D1%8B_%D0%B2_%D0%90%D1%81%D1%82%D1%80%D0%B0%D1%85%D0%B0%D0%BD%D0%B8):
19 мая 2021 г. в 15:00 ВСВ на станции наблюдалась сильная пыльная буря
(видимость 200 м, западный ветер до 21 м/с).
